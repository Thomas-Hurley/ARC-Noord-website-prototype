### Projectnaam = Kunstrolschaatsclub W.K.C

### Korte beschrijving
Ons project gaat over de vereniging Kunstrolschaatsclub W.K.C.

### Doel van het project
Het doel van ons project is om de website helemaal te gaan redesignen en zorgen dat niet alles meer via facebook gepost hoeft te worden.

### Gebruikte technologieën
* HTML/CSS
* Tailwind CSS
* Javacript

### Korte uitleg structuur
* Main/ – hoofdmap van het project
* Img/ – afbeeldingen (icons, foto’s, graphics)
* Js/ – JavaScript-bestanden
* Pages/ – extra HTML-pagina’s (subpagina’s)
* Home.html – start-/homepage
* PvE.md – documentatie of uitwerking (bijv. Plan van Eisen)
* README.md – uitleg over het project (wat het is, hoe je het gebruikt)
